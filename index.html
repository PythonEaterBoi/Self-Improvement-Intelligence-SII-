Learning should be transparent.

In this static demo, mini-agents are local feedback helpers—not Gemini services. Nothing is sent to a server. Helpful feedback can be saved in this browser as review examples; it does not update model weights.

DATA & LEARNING

Keep the loop honest.

This GitHub Pages build runs entirely in your browser. It uses a small set of bundled prompt patterns and deterministic specialist templates; it does not ship or train a PyTorch model, call Gemini, or upload your prompts.

SmolTalk: SII is designed to use Hugging Face's HuggingFaceTB/smoltalk as a future training-data source. The full dataset is not bundled here. Review its license, access terms, and split format before downloading or using it.

Feedback examples are stored locally in this browser only. Export them to review or remove them. Feedback is not automatically treated as correct training data.
